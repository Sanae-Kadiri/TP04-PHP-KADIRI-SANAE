# TP04-PHP : Programmation orientée objet 

**Auteur :** KADIRI Sanae


**Module :** Programmation Web 2 - 2026/2027

Ce dépot contient les exercices du TP4 sur la programmation orientée objet en PHP.

## Lancer un fichier 

Ouvrir un terminal dans le dossier du projet, puis :

    php partie1.php

Avec XAMPP sous Windows : 
    
    & "C:\xampp\php\php.exe" partie1.php

## Fichiers

| Fichier | Contenu |
|---|---|
| `partie0.php` | La premiere classe (voiture) |
| `partie1.php` | Visibilite et encapsulation (Personne) |
| `partie2.php` | Constructeurs et destructeur | 
| `partie3.php` | Methodes magiques __set, __get, __isset, __unset |
| `partie4.php` | __toString |
| `partie5.php` | __serialize et __unserialize |
| `partie6.php` | Heritage (Animal, Etudiant), final, readonly | 
| `partie7.php` | Compte Bancaire |
